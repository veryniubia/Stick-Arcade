# Stick Arcade v1.0 — M5Burner Description

## English

Stick Arcade is a pixel-art mini-game collection for M5Stack StickS3. Version 1.0 includes Throwhalla, a tilt-aimed weapon duel, and Big Bump, a portrait sumo game. Play solo or connect two StickS3 devices directly over ESP-NOW—no router or internet is needed. Both players need compatible firmware. Controls are shown on screen; A and B are the action buttons. Open-source project (MIT): https://github.com/veryniubia/Stick-Arcade

## 简体中文

Stick Arcade 是面向 M5Stack StickS3 的像素风小游戏合集。v1.0 包含倾斜瞄准、投掷武器的对战游戏 Throwhalla，以及竖屏相扑游戏 Big Bump。支持单人游玩，也支持两台 StickS3 通过 ESP-NOW 直连对战，无需路由器或互联网。联机双方需使用兼容固件。操作提示显示在屏幕上，A、B 为主要操作键。项目采用 MIT 许可证：https://github.com/veryniubia/Stick-Arcade
