# Stick Arcade v1.0 — Release Notes

## English

### What's included

- **Throwhalla:** tilt to aim and throw weapons in a two-player lava-arena duel; includes multiple weapons and powerups.
- **Big Bump:** a portrait sumo game with inflatable bursts, hazards, and collectible items.
- **Solo play** for both games and **two-device multiplayer** over ESP-NOW. Multiplayer pairs compatible StickS3 devices directly, without a Wi-Fi router.
- A shared launcher and settings for sound, brightness, tilt sensitivity, and calibration.
- Host-side gameplay and network tests, plus PlatformIO build configurations for the full firmware and individual games.

### Compatibility

Designed for M5Stack StickS3. For multiplayer, both devices must run compatible firmware and game protocol versions. Use the `m5stack-sticks3` PlatformIO build for the normal release firmware; debug builds are for development only.

### Project

Source code and game-development guide: https://github.com/veryniubia/Stick-Arcade

## 简体中文

### 本版本内容

- **Throwhalla：** 倾斜设备瞄准，在熔岩竞技场中投掷多种武器对战，并使用场内道具。
- **Big Bump：** 竖屏相扑游戏，使用充气冲撞，在危险场地中争夺道具。
- 两款游戏均支持**单人模式**和通过 ESP-NOW 进行的**双机联机**。联机设备可直接配对，无需 Wi-Fi 路由器。
- 共用启动器和设置页，支持调整音量、亮度、倾斜灵敏度及传感器校准。
- 提供主机端规则与网络测试，以及完整固件和单游戏的 PlatformIO 构建环境。

### 兼容性

本固件面向 M5Stack StickS3。联机时两台设备需运行兼容的固件和游戏协议版本。普通发布固件使用 PlatformIO 的 `m5stack-sticks3` 环境构建；调试固件仅供开发使用。

### 项目

源码与游戏开发指南：https://github.com/veryniubia/Stick-Arcade
