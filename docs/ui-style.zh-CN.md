# Stick Arcade 界面风格

## 战斗反馈

- 命中文字按本机玩家的视角显示。得分用黄色 `HIT!`，受击用红色 `OUCH!`，由 `ui::hitNotice` 绘制。文字直接叠在场景上，用黑色投影保证亮背景上的对比度。
- 横屏游戏在屏幕上方居中显示，字号为 3，持续约 0.7 秒。Big Bump 使用角色上方的小字，让玩家看得出谁撞到了尖刺。
- 决胜一击优先显示胜负。`ui::matchResult` 统一绘制绿色 `YOU WIN`、红色 `YOU LOSE` 或黄色 `DRAW`。比分在顶部查看。
- 搜索、加入、倒计时、再战和退出确认由平台绘制。游戏提供大厅场景和专属操作说明，给平台提示留出空间。

## 道具

- 道具用自身轮廓和配色识别，图标周围留空。生成预告可用闪烁或十字标记。
- 同名道具共用同一个绘制函数，场内拾取物与状态栏也沿用同一图案。汉堡统一调用 `ui::drawBurger(centerX, centerY)`，以像素中心定位。
