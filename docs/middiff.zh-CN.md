# MidDiff：中门对狙

第一人称对狙。双方各守一侧，中间隔着一段空地，各自面前有一堵半高掩体。需要 M5Stack Unit Joystick2 摇杆（接 Grove 口），没有摇杆无法进入。

## 操作

横屏握持，摇杆在左手，A/B 在右手。

| 操作 | 作用 |
|---|---|
| 摇杆 | 前后左右移动。方向始终相对玩家自己，**与视角朝向无关**。 |
| 转动设备 | 改变视角：水平在正前方左右各 90°（共 180°），上下各 30°。角度有放大：中心附近放大倍数小、便于精瞄，越靠边缘越大，设备左右各转约 36° 即可转到极限。 |
| 按下摇杆 | 重新居中视角（陀螺仪会漂移时使用）。 |
| A | 开枪，瞬发命中，射击间隔 1.1 秒。 |
| B（按住） | 蹲下，消耗体力。 |
| 快速摇晃两次 | 退出确认（取消后视角重新居中）。 |

视角：转动设备像拿着一扇窗户看世界。设备向右转，视角向右；设备上边缘向自己这边倒（屏幕朝下），视角向上抬。水平转动由陀螺仪积分得到，会有缓慢漂移，需要时按摇杆居中；俯仰以重力为参照，不会漂移。灵敏度跟随设置页的 AIM 档位（整体放大倍数）。

## 场地（单位：米）

- 每人一个 7 m × 3.75 m 的活动区，前缘是不可跨越的线（地面黄黑斜纹）。两人之间始终相距 11.5 m 以上。
- 每人活动区前方有一堵 2.6 m 宽、1.15 m 高的掩体。
- 站立：眼高 1.65 m，头部和上半身露出掩体；蹲下：身高 1.0 m，躲在掩体后完全不可见，但自己也看不到掩体对面，需要站起或走到掩体侧面才能射击。
- 从掩体两侧露出身体可以改变暴露程度；允许蹲着移动（速度减半）和射击。

## 战斗

- 生命值 100。头部一枪致命，身体 50。头部判定略大于实际头，方便陀螺仪瞄准。
- 命中判定为从眼睛沿视线的射线，会被两侧掩体和地面挡住。双方同一帧互相命中则本回合平局。
- 体力：蹲下每秒消耗 34%，耗尽后强制站起，且必须松开 B 并恢复到 30% 才能再蹲；松开 0.5 秒后开始每秒恢复 30%。
- 回合：先打倒对手得一分，联机先赢 3 回合获胜；45 秒内无人倒下则按剩余生命值判定，相同则平局。回合开始 0.5 秒内不能开枪。

## 单人模式

对手始终使用空输入（遵循项目约定：不做对手 AI），站着不动、不射击、不蹲。每次打倒后靶子在活动区内随机位置重新出现（有时在掩体后，有时在掩体外），累计 `KILLS`，无限练习，没有回合时间限制。

## 摇杆缺失

选中游戏卡片时，启动器给摇杆接口供电并检测，卡片底部显示 `JOYSTICK READY` / `NO JOYSTICK FOUND`，没有摇杆按 A 会提示无法进入。游戏中摇杆被拔出或读取失败超过 0.8 秒时，提示 `JOYSTICK LOST` 并退出联机、返回启动器。

## 联机

主机权威模拟，客户端发送摇杆、视角和按键。游戏 wire ID 为 6，协议版本 1；会话协议版本 4（输入包增加了视角俯仰和摇杆）。联机两端需要相同固件。客户端本人的视角直接来自本地传感器，不等主机回传。

## 实现与调参

- 规则：`src/games/middiff/middiff.*`（不依赖硬件，主机端可测试）。所有数值是 `MidDiffGame` 中的 `constexpr`。
- 画面：`middiff_view.cpp`，真实针孔投影的轻量软件渲染（地面、墙、掩体和一个角色，约 40 次多边形填充），实机约 5.8 ms/帧，60 FPS。
- 陀螺仪与摇杆：`src/core/gyro_look.h`、`stick_map.h`、`joystick.*`。如果实机上某个方向反了：摇杆改 `joystick.cpp` 顶部的 `kSwapAxes/kInvertRight/kInvertForward`，视角改 `GyroLook::kYawSign/kPitchSign`。
- 测试：`python test_host/run_tests.py`（`middiff_test` 覆盖规则、编解码、陀螺仪、摇杆映射；`net_test` 覆盖联机）。画面预览：`python test_host/preview_middiff.py`。
