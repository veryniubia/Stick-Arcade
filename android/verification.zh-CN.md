| 固件 | 全游戏环境 m5stack-sticks3 构建成功。静态 RAM 62,116 / 327,680 字节，Flash 1,199,177 / 3,342,336 字节。esptool 4.9 镜像校验通过。 |
| 实物刷写 | COM6 识别为 ESP32-S3-PICO-1、8 MB Flash、8 MB PSRAM。四段写入成功，esptool 校验通过并复位。刷写前后分别读回 0x9000 起的 20,480 字节 NVS，SHA-256 相同。 |
| APK | SDK 35、NDK r27d、JDK 21。arm64-v8a APK 通过 v2/v3 签名、固定证书指纹和 16 KB ZIP 对齐检查。覆盖安装到 Android 9 / API 28 模拟器成功。 |
| APK 四游戏 | 模拟器通过原菜单进入每款游戏并开始单人。Big Bump 竖屏，其余横屏；MidDiff 通过模拟传感器校准。各游戏切后台再返回均回到启动器。截屏和控制区按实际布局核对。 |
| 帧率与日志 | 从系统文件选择器实际导出并读回 6,576 字节日志。本次模拟器单人样本 Throwhalla 60、Big Bump 53–60、MoonDuel 60、MidDiff 60 fps。这些值是短时采样，单人 RTT 显示空值。 |

| 输入与回归 | JVM 验证多指持有、跳跃、独立释放、取消归零、四个旋转和单位换算。主机规则、设置旧字节、输入、网络及再战测试通过。Windows 模拟器通过四游戏、双端联机、校准、窗口和设置持久化回归。 |
